# VisOKR · 个人目标管理（Vis 体验 × OKR 引擎）

一个**单文件 PWA**，交互复刻 iOS 应用 <b>Vis</b>（摘要 / 目标库 / 任务 / 我的），内核融合 OKR 方法论（度量类型、权重、节奏对照、复盘快照）。数据默认存本机 localStorage，可选通过**私有 GitHub 仓库**多端自动同步——零后端、零账号、零费用。

> 线上地址：<https://karachends.github.io/okr-tracker/>
> 本地文件：`~/Documents/AI Works/做一些小应用/okr-tracker/`

## 核心机制

- **目标 Goal**：名称 + **emoji 图标**（表单可选，默认🎯）+ 日期区间（可空=未计划）+ 目标组；摘要卡以「emoji+外圈进度环」呈现整体进度（不展开发数细节，点卡进详情）；每个目标自动分配主题色，贯穿进度条/时间轴条/拆分卡/任务行。标题前显示 **x/y 任务完成数**（有关联任务时）；进度 = 各拆分目标完成度的**简单平均**；状态自动派生（进行中/未计划/未开始/已结束/已归档）。摘要页**按住紫条左右拖**可按天吸附平移工期，轻点进详情；详情页可归档（目标库「已归档」找回）或删除（任务自动解关联）。
- **拆分目标 Subgoal**：四种度量类型，编辑时底部有大白话示例提示。计数 `0→10 ⭐`；递减 `79.4 ↘ 76`（减重/砍订阅）；百分比 `64 / 100%`；是否 `✓`。卡片底部迷你进度条显示各自完成度，无权重/单位概念。
- **任务日历（默认视图）**：任务页默认日历形态，支持**周/月/年**三种视图与 ‹ › 快速翻页（周翻 7 天、月翻月、年翻年），每天格子里有状态点（紫=有待办、绿=全完成、渐变=混合），点选任意日期查看/管理当天任务；**未来日只读不可打卡**。视图模式与所选日历形态**跨切页记忆**。☰ 可切回列表模式（同样记忆）。
- **列表模式规则**：非今日任务（明天/之后）以**简化行**展示且无打卡按钮，仅可点开编辑；今日/已逾期/未计划为完整交互行。
- **周一始日期选择器**：任务日期、目标起止等所有日期选择均为自绘月历（周一起始、今天红圈、支持清除/回到今天），不再依赖系统原生 date input。
- **页签导航栈**：每个页签维护自己的**页面栈**——首页→目标组→目标详情，返回按钮**逐级弹栈**（回组而不是跳回首页）；切走再回恢复整条栈；每层**滚动位置**一并记忆；删除目标时自动从所有栈剔除死页面。目标卡可多张同时展开且全部记忆。
- **任务 Task（周期配额模型）**：任务挂在**拆分目标**下，完成即推进它，行上显示影响 `⬆ 8.33%`。**任务行底色/标题色继承所属目标配色**，逾期红色分组，**备注**字段记录执行细节。
  - **完成方式**：计数（⭐+N）/ 百分比（%+N）/ 是否（✓）三种。表单内置类型批注：计数=小而明确的任务、百分比=周期循环目标（推荐量达成率）、递减=往下压的指标、是否=一次性。
  - **当前值来源可选**：编辑拆分目标时勾选「当前值由关联任务自动计算」→ 显示推导值（达成率/推进合计）、隐藏手填；取消勾选 → 回到手动设定与 ＋ 按钮推进。存量数据自动迁移（有关联任务的默认开启）。
  - **周期 + 额度（每日一次打卡）**：设「每周/每两周/每月/每年 + 每周期完成 N 次」后，任务在窗口内**每天都出现**；**每个自然日最多打卡一次**（同日再点=取消今日，重复打卡会提示），圆圈显示累计 `2/3`；**满 N 次自动记本期完成**进已结束，可从已结束点掉撤销最近一次；支持在今日视图**补卡**窗口内过去日期（未来日/窗口外拒绝）。下一周期窗口自动滚动、次数清零，任何页面渲染前先滚动。月末钳制（1/31 起每月 → 2/28）。
  - **创建时不填时间**——本期达成时弹「记录用时」填实际起止（可跳过），已结束显示 `19:00 - 20:10` 时段；撤销标记自动回退推进量，最后一次撤销会清空用时。
  - 例：拆分目标「每周力量训练≥3次·12周」+ 任务「力量训练·每周·额度3·计数+1」——本周练一次标一次，标满 3 次本周达标，拆分目标 +3。
- **复盘 Record**：目标详情页每周一条，信心度 🟢 + 进度快照 → 详情页趋势线；超 8 天未复盘亮「待更新」；复盘页显示 🔥 连续复盘天数。
- **摘要数据看板（v4.2，接打卡数据）**：
  - **打卡节奏**：两条累计曲线——灰虚线 = 推荐量（额度 × 已过周期数），绿实线 = 实际打卡；底部直接给判词「超前 N 次 💪 / 欠账 N 次」。
  - **打卡热力**：近 91 天格子 = 每天打卡次数（深浅），紫框 = 当天写过复盘，🔥 = 连续打卡天数。
  - 数据基础：周期任务的 marks **跨周期保留历史**（滚动只推进窗口不清打卡），额度判定只看本窗口。
- **摘要三件套**：座右铭宣言横幅（❝ 一句话，随同步走）；**分段圆环**——季度卡中心环按目标分弧、每弧填充=该目标进度；周时间轴条按目标着色。
- **目标组**：可配 emoji 图标（🥗📚…），行内 ✎ 快速改名换图标。
- **节奏引擎**：目标进度 ÷ 时间进度 ≥90% 正常 / ≥65% 偏慢 / 否则落后；季度卡汇总全部目标 vs 日历。

## 色彩语义规范（v4.10）

一色一义，杜绝混用。摘要看板底部常驻图例。

| 颜色 | 唯一语义 | 出现位置 |
|---|---|---|
| **目标色**（9 色调色板） | 身份：属于哪个目标 | 甘特条、emoji 进度环、拆分卡、任务行底色/勾选圈、进度条、⭐徽章、侧栏环 |
| **绿** `--ok` | 完成：打卡、全部完成、达成 | 打卡热力深浅、日历"全部完成"点、勾选填充、节奏徽章「正常/已完成」、同步 OK |
| **蓝** `--accent` | 待办 / 记录（行动类） | 日历"有待办"点、热力"写过复盘"蓝框、选中日期、今日任务计数、主按钮 |
| **琥珀** `--warn` | 需注意（非紧急） | 节奏「偏慢」、「待更新」徽章、「该复盘了」、🔥streak、未来日提示 |
| **红** `--red` | 紧急 | 节奏「落后」、逾期、今天的红线/红标 |

> 历史问题：紫色曾同时表示"目标身份/有待办/写过复盘"，红色曾同时表示"落后/待更新/今天"。现已收敛为上表的一一映射；品牌装饰（宣言横幅、选中态）不承载数据语义。

## 多设备同步（可选）

原理：整份状态 JSON 作为文件存在**私有**仓库 `KaraChenDS/okr-tracker-data`（`okr.json`），走 GitHub Contents API，客户端分层合并（按 id + updatedAt，删除以墓碑传播）。

**安全规则**：代码里只有 `owner/repo/path`，**没有任何令牌**；令牌只存每台设备 localStorage；导出与同步载荷均不含令牌（有测试断言）。

### 开启步骤（每台设备一次）

1. GitHub → Settings → Developer settings → **Fine-grained tokens**：只勾 `okr-tracker-data`，权限 **Contents: Read and write**。
2. 打开应用 → 我的 → 多设备同步 → 粘贴令牌 → 「保存并测试」。
3. 其他设备：设置页「复制连接链接」（`#t=` 一键填令牌，发给自己后记得撤回）。
4. 之后无感：启动拉取、改动 2.5s 防抖推送、切回前台/联网补拉；状态点在右上角。

## 三端适配

PC 横屏（≥1024px）侧栏含目标直达列表：分组标题 + 每个目标的 emoji 进度环，点击即跳转。

- **手机（≤640px）**：底部悬浮胶囊导航 + 单列卡片 + FAB，安全区适配，可离线加主屏。
- **iPad（641–1023px）**：内容加宽至 800px，目标卡双列、拆分卡三列、看板双栏，保留底部胶囊（横屏单手友好）。
- **PC（≥1024px）**：左侧边栏导航（品牌 + 四项 + 同步状态脚注），980px 内容区双列，FAB 右下角，弹层居中。
- 全部断点经 390/834/1024/1440 四档自动化验证：无横向溢出、导航形态正确、列数正确。
